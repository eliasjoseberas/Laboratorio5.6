# Laboratorio5.6


# Sistema de Inventario

Este proyecto fue realizado en C# como parte del
Laboratorio 5.6 de Fundamentos de Programación.

## Descripción

El programa permite crear productos utilizando
una clase llamada Producto.

Cada producto contiene:
- Codigo
- Nombre
- Precio
- Cantidad

## Funcionalidades

- Crear productos.
- Mostrar informacion de cada producto.
- Calcular el valor total de las unidades disponibles.
- Comprobar la independencia de los objetos.

## Archivos

- Program.cs
- Producto.cs

## Ejecucion

Abrir el proyecto en Visual Studio y ejecutar
la aplicacion de consola.
